# Verification outputs

These files are generated by the scripts in `../scripts/`.

- `rational_base_verification.json` and `.txt` record the exact component
  counts, geometry, decisive signs, total of 40 crossings, and the smallest
  strict margin `151/23400`.
- `rational_base_exact_sign_table.csv` contains the 66 exact rows reproduced in
  the manuscript appendix.
- `local_family_verification.json` and `.txt` record seven exact symbolic
  identities, 2080 rational-grid parameter checks, and three direct numerical
  component computations.
- `closed_form_verification.json` and `.txt` verify the period-16 formulas and
  displayed periodic optimizers for every `n` from 0 through 4096.

Run `python3 scripts/run_all_checks.py` from the bundle root to regenerate all
outputs and compare the manuscript appendix with the CSV certificate.
